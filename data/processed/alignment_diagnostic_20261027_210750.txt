6. SENSOR WINDOW vs EDA-BASED TAG BOUNDARIES (project logic replicated)
==============================================================================
Project selection rule (from src/preprocessing.py):
  EDA/HR/TEMP/BVP: index = int(t - THIS SIGNAL's own first timestamp);
                   window = index in [int(tag_i_rel), int(tag_j_rel)]
                   where tag_rel = tag_utc - EDA first timestamp.
  IBI            : offset_s (relative to IBI's OWN header time) in [t0, t1).
  ACC            : chunk counter (32 samples = 1 'second') from ACC's own start.
So a signal whose header starts D seconds after EDA is read D seconds EARLY
relative to the EDA-based boundaries:  shift = signal_start - EDA_start.
A 'synthetic 10 s offset' therefore appears exactly when a header starts 10 s after EDA.
